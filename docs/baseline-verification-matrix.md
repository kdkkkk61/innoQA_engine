## 1. 매트릭스 정의

- **행 = 필드 전수**: sc0 yaml 스키마 + Chrome 실측이 기준 (page 상수 SEL_C_* 와 1:1).
  "입력·저장 가능한 모든 필드" — 눈에 띄는 필드만이 아니라 토글·조건부·숨김 포함.
- **열 = 기본 검증 클래스**:

| 클래스 | 내용 | 담당 sc |
|--------|------|---------|
| 존재 | yaml↔DOM diff(추가/삭제/숨김) | sc0 |
| 조건부 노출 | gating 트리거별 노출/숨김 매핑 | sc1 (예: 폴더동기화 sc1e 스케줄 4종) |
| 초기값 | 텍스트 빈값 / select·radio 기본 / 토글 OFF | sc2 (예: sc2e 스냅샷) |
| maxlength·clamp | DOM 속성 + **실타이핑**(type_real — fill 은 마스크 우회라 금지) | sc2(속성)/sc3(clamp 실측) |
| 형식 | 숫자 필드에 문자·음수·0 수용 여부 | sc2(수용)/sc3(저장 처리) |
| required | 빈값 제출 → 경고 (필수 순서 + **조건부 하위 required** 포함) | sc2(순서)/sc3(스케줄 하위 등) |
| 중복 | 고유명 필드 재등록/rename | sc3/sc4 |
| 특수문자 | 이름류 필드 허용/차단 수집 | sc3/sc4 |
| 오버플로 | **서버측 자유입력 전수** 3000자 (클라 clamp 필드는 실측 근거로 제외) | sc3(생성)/sc4(수정, merge_key 공유) |
| roundtrip | **저장 가능 필드 전수** 저장→재오픈 대조 | sc5a (+ sc4 수정 반영) |

- **셀 상태 3종**: ①커버(sc 참조) ②**근거 있는 제외**(실측 주석 필수 — "왜 안 하는지"가 코드/yaml 에 남아야 함) ③갭(마감 전 채움).

## 2. 제외 규칙 — "안 하는 것도 실측 근거로"

| 제외 | 근거 형식 (실례 — 폴더동기화) |
|------|------|
| 오버플로 제외 | 클라 clamp 실측: 설정명(30)·파일용량(30)·분주기(3) — sc2f 가 maxlength 실측 후 sc3k 주석에 제외 근거 명시 |
| 서버 가드 확인됨 | 설명 3000자 → '최대 300자' 경고 (sc3i 실측) — raw 서버 오류와 구분해 기록 |
| 검증 자체 불가 | 타입 필터: 단일 타입 탭 + 리스트에 타입 컬럼 없음(sc1b 헤더 실측) → [SKIP] 사실 기록 (sc3p) |
| 기능 부재 | Example/Import 버튼 없음(실측) → docstring N/A 명시 |
| 자동화 경계 | 관리자 비번 인증/암호화 — user-driven ([수동 확인 필요] warn) |

## 3. 폴더동기화 적용례 (매트릭스 감사 결과 — 2026-07-07)

감사에서 나온 갭 3건과 채움 (같은 실수 반복 방지용 기록):

| 갭 | 왜 생겼나 | 채움 |
|----|----------|------|
| 원본위치 3000자만 검증 (대상/확장자 누락) | 주목 필드만 깊게 — spot-check | sc3k/sc4j 요소 3종 루프(원본/대상/확장자 — extensionIncludes 는 maxlength=None 실측이라 포함) |
| 숫자 필드 형식(문자·음수·0) + isOriginRemove 토글 2종 완전 미커버 | 조건부·수수한 필드가 시야 밖 | sc2g |
| 스케줄 하위 required (정상값 커밋만 확인) | happy-path 만 | sc3u (매분 빈값/0, 매주 요일 0개) |
| roundtrip 5요소뿐 (대상/확장자/용량/토글 빠짐) | 대표 필드만 | sc5a 10요소 전수 |
